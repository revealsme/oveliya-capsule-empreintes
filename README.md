# OVELIYA Capsule — empreintes

Ce dépôt garde, version après version, les empreintes SHA-256 des fichiers d'OVELIYA Capsule, publiés sur https://oveliya.com/capsule/.

Elles sont publiées ici, hors du site, pour une raison simple : si l'hébergement du site était un jour compromis, ces empreintes permettraient de voir que la page servie n'est plus celle publiée.

Vérifier un fichier : téléchargez-le depuis oveliya.com/capsule/, calculez son SHA-256 (sha256sum sous Linux ou Mac, Get-FileHash sous Windows), et comparez-le à la ligne correspondante de Capsule-empreintes.txt.

L'historique de ce dépôt date chaque version.
